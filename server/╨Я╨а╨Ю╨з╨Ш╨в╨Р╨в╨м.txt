Этой папке не хватает файла с базой шахматных пазлов:

  puzzles.csv

Он не хранится в репозитории (слишком большой для GitHub + не является кодом).

Если он тебе нужен:

1. Скачать открытую базу пазлов Lichess (формат такой же/похожий, CSV):
   https://database.lichess.org/#puzzles
   Скачанный файл положить в эту папку и переименовать в puzzles.csv.

После того как файл появится в этой папке (server/), импорт пазлов в базу
делается из КОРНЯ проекта через:

  node scripts/import-puzzles.js

(см. сам скрипт — там может понадобиться настроенный .env с DATABASE_URL).
